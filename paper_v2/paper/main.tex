\begin{abstract}
Conversational agents powered by large language models must decide which interaction turns to persist in long-term memory. Production systems typically rely on training-free distance heuristics, storing an utterance whenever its cosine similarity to prior entries falls below a fixed threshold. In practice, this heuristic scales linearly ($O(N)$) with memory store size and degenerates into an unselective filter that commits over 99\% of turns, degrading vector index retrieval. Alternatively, prompting small language models (SLMs) to classify memory relevance incurs 45\text{--}90~ms of latency per turn, stalling interactive dialogues. We present \textbf{LSG (Lightweight Supervised Gate)}, a constant-time ($O(1)$) write gate based on a shallow stacked ensemble. LSG combines frozen Sentence-BERT embeddings, short-horizon history pooling, conversational metadata, and Platt-calibrated base classifiers feeding a logistic regression meta-learner. On a held-out cross-domain benchmark evaluated against human intent annotations, LSG requires 0.153~ms of total CPU time per turn (0.143~ms for embedding and 0.010~ms for classification). This represents a $294\times$ latency reduction over Qwen2.5-0.5B and $555\times$ over Llama-3.2-1B at comparable ranking precision (AUPRC 0.569 vs. 0.568\text{--}0.574). Dedicated extraction pipelines such as Mem0 achieve higher AUPRC (0.615) but capture only $20.2\%$ of positive turns while requiring 90.0~ms per decision. While cross-domain covariate shift induces a calibration penalty ($\text{ECE} = 0.401$), LSG preserves monotonic ranking while reducing per-turn gating overhead by multiple orders of magnitude.
\end{abstract}

\section{Introduction}
\IEEEPARstart{L}{ong-horizon} conversational agents must maintain persistent state across hundreds of turns to preserve user preferences, task parameters, and entity relationships~\cite{packer2023memgpt,chaudhary2024mem0,zhang2024amem,park2023generative}. In retrieval-augmented generation architectures, the agent's long-term utility depends on its write-time ingestion policy. An unselective gate writes ephemeral chit-chat and acknowledgments into durable storage, inflating the retrieval index, increasing semantic search latency, and introducing noisy distractors into downstream prompt contexts. Conversely, an overly strict gate misses critical user constraints, causing permanent loss of context.

In production frameworks, write filtering is almost universally delegated to heuristic cosine similarity thresholds: a turn is stored only if its maximum cosine similarity to existing records falls below a threshold $\tau$. While conceptually straightforward, distance-based filtering exhibits two core weaknesses in practice. Computing pairwise similarities against an expanding memory store requires $O(N)$ comparisons per turn, introducing a latency tax that compounds as interaction histories grow. Furthermore, cosine distance treats utterances as isolated semantic vectors, failing on conversational turns whose salience depends on dialogue context. For instance, when an assistant asks \textit{``Do you have any dietary restrictions?''} and the user replies \textit{``I have a severe peanut allergy,''} the user utterance conveys a critical permanent attribute; however, in isolation from dialogue history, single-turn distance scanning misidentifies such responses as low-salience fragments. When tuned to preserve recall, distance thresholds degenerate into near-total pass-through filters, writing over 99\% of turns and forfeiting selective control.

Small language models (SLMs) such as Qwen2.5-0.5B and Llama-3.2-1B, as well as specialized extraction pipelines like Mem0, offer stronger semantic discrimination. However, invoking a language model on every dialogue turn adds 45\text{--}90~ms of latency on commodity hardware. For streaming, real-time agent runtimes where turn latencies must remain bounded, this computational cost is prohibitive.

We design \textbf{LSG (Lightweight Supervised Gate)}\footnote{Source code and implementation are available at \url{https://github.com/24f2007601/LSG-LIghtweight-Agentic-Memory}}, a constant-time ($O(1)$) write gate tailored for sub-millisecond execution on standard CPU hardware. LSG pools Sentence-BERT~\cite{reimers2019sentence} embeddings across a short history window ($K=2$), extracts five conversational metadata signals (speaker role, pronoun density, utterance length, question markers, and entity mentions), and passes the concatenated representation to a stacked ensemble comprising logistic regression, gradient-boosted decision trees (XGBoost), and a multilayer perceptron. Each base classifier undergoes cross-validated Platt scaling before a second-stage logistic regression meta-learner produces the final write probability.

In cross-domain evaluation on held-out PersonaChat turns evaluated against annotated human intent labels, LSG achieves an end-to-end latency of $0.153\text{ ms}$ per turn on a single CPU thread ($0.143\text{ ms}$ for feature encoding and $0.010\text{ ms}$ for ensemble classification). This delivers a $294\times$ speedup over Qwen2.5-0.5B and $555\times$ over Llama-3.2-1B while achieving comparable ranking quality ($\text{AUPRC} = 0.569$ vs. $0.568\text{--}0.574$; $\text{ROC-AUC} = 0.566$ vs. $0.529\text{--}0.533$). While extractive pipelines like Mem0 deliver high precision and AUPRC ($0.615$), they record an omission rate near $80\%$ ($\text{Recall} = 0.202$) at $580\times$ higher latency ($90.0\text{ ms}$). We also examine the interaction between post-hoc Platt calibration and cross-domain covariate shift, identifying how distribution changes across dialogue genres affect confidence estimation.

\section{Related Work}

\subsection{Agent Memory Architectures}
Architectures such as MemGPT~\cite{packer2023memgpt} and A-MEM~\cite{zhang2024amem} manage multi-tiered memory hierarchies via LLM function calling, while Mem0~\cite{chaudhary2024mem0} deploys SLM-driven fact extraction pipelines. While these methods extract structured facts, prompting an LLM or SLM on every dialogue turn introduces 50\text{--}100~ms of latency and substantial compute costs, making per-turn write classification a bottleneck in interactive systems.

\subsection{Novelty Filtering and Calibrated Ensembles}
Information retrieval systems historically relied on Maximal Marginal Relevance (MMR)~\cite{carbonell1998mmr} and thresholded cosine distance to eliminate redundant documents. When applied to streaming conversational memory, pairwise distance scanning requires $O(N)$ operations against $N$ stored memories and cannot distinguish transient chit-chat from durable personal preferences. Supervised stacked generalization~\cite{wolpert1992stacked} combines diverse classifier families (linear, tree-based, neural) to produce balanced decision boundaries. In parallel, post-hoc Platt scaling~\cite{platt1999probabilistic} fits a logistic sigmoid over raw model outputs to align predicted scores with empirical event likelihoods~\cite{guo2017calibration}. We combine these techniques into an $O(1)$ write filter for conversational streams.

\section{Problem Formulation}
Let a dialogue session consist of a sequence of streaming turns $\mathcal{S} = \{x_1, x_2, \dots, x_T\}$. At each time step $t$, the agent receives utterance $x_t$ along with conversation history $\mathcal{H}_t = \{x_{t-K}, \dots, x_{t-1}\}$. The memory gate $g_\theta$ outputs a binary decision $y_t \in \{0, 1\}$, where $y_t = 1$ denotes $\text{STORE}$ (commit to long-term memory) and $y_t = 0$ denotes $\text{IGNORE}$ (discard).

\subsection{Evaluation Criteria}
We evaluate gating mechanisms across four primary dimensions:
\begin{enumerate}
    \item \textbf{Discriminative Ranking}: Area Under the Precision-Recall Curve (AUPRC) and ROC-AUC across decision thresholds.
    \item \textbf{Matched Operating Points}: To address the distorted $F_1$ scores caused by degenerate 100\% recall baselines, we evaluate $F_1$ at fixed recall ($F_1@R=0.85$) and fixed precision ($F_1@P=0.70$).
    \item \textbf{Net Memory Utility}: We compute net agent memory utility as:
    \begin{equation}
        \text{Utility} = \text{Precision} - \lambda \cdot \text{Write Rate}
    \end{equation}
    where $\text{Write Rate} = \frac{1}{T}\sum_{t=1}^T \hat{y}_t$ and $\lambda \in [0, 1]$ parameterizes the cost of vector store bloat. We fix $\lambda = 0.3$ to reflect typical indexing overhead, storage cost, and retrieval token inflation relative to precision.
    \item \textbf{Calibration \& Latency}: Expected Calibration Error (ECE) across $M=10$ equal-frequency confidence bins, and per-turn wall-clock latency divided into end-to-end processing ($t_{\text{turn}} = t_{\text{embed}} + t_{\text{clf}}$) and isolated classifier forward execution ($t_{\text{clf}}$).
\end{enumerate}

\section{The LSG Architecture}

\subsection{Contextual Encoding and Metadata Extraction}
To capture context dependence without autoregressive overhead, we compute a recency-weighted average of Sentence-BERT~\cite{reimers2019sentence} embeddings over history window $K=2$:
\begin{equation}
    \mathbf{h}_t = \sum_{k=0}^{K} \gamma^k \cdot \mathrm{SBERT}(x_{t-k})
\end{equation}
where $\gamma = 0.7$. We concatenate $\mathbf{h}_t$ ($384$-dim) with a $5$-dimensional dialogue metadata vector $\mathbf{m}_t$:
\begin{equation}
    \mathbf{m}_t = [\text{role}_t, \text{len}_t, \text{is\_question}_t, \text{pronoun\_count}_t, \text{has\_entity}_t]
\end{equation}
forming the unified feature representation $\mathbf{z}_t = [\mathbf{h}_t \,\|\, \mathbf{m}_t] \in \mathbb{R}^{389}$.

\subsection{Stacked Meta-Learner with Platt Calibration}
The representation $\mathbf{z}_t$ feeds three base classifiers selected for structural diversity: an $L_2$-regularized logistic regression model for linear boundary separation, gradient-boosted decision trees (XGBoost, 100 estimators, maximum depth 4) to capture non-linear feature interactions, and a single-hidden-layer multilayer perceptron (128 ReLU units with early stopping).

Each base classifier $m \in \{\text{LR}, \text{XGB}, \text{MLP}\}$ is calibrated with 5-fold cross-validated Platt sigmoid scaling:
\begin{equation}
    P_m(\mathbf{z}_t) = \frac{1}{1 + \exp(A_m f_m(\mathbf{z}_t) + B_m)}
\end{equation}

The calibrated probability vector $\mathbf{p}_t = [P_{\text{LR}}, P_{\text{XGB}}, P_{\text{MLP}}]$ is passed to a second-stage Logistic Regression Meta-Learner that computes the final ensemble confidence:
\begin{equation}
    \hat{p}_t = \sigma(\mathbf{w}^T \mathbf{p}_t + b)
\end{equation}

\subsection{Domain Adaptation}
When adapting to a target domain with small annotated samples ($N \le 100$), we introduce a linear projection $\mathbf{W} \in \mathbb{R}^{d \times d}$ and bias vector $\mathbf{b} \in \mathbb{R}^d$:
\begin{equation}
    \tilde{\mathbf{z}}_t = \mathbf{W} \mathbf{z}_t + \mathbf{b}
\end{equation}
where $\mathbf{W}$ is initialized to the identity matrix $\mathbf{I}$ and $\mathbf{b}$ is optimized via few-shot gradient descent to align target-domain class centroids without retraining the ensemble weights.

\section{Experimental Evaluation}

\subsection{Experimental Setup}
We train LSG on the Bitext Customer Support dataset ($2,000$ turns) and evaluate zero-shot transfer on the held-out PersonaChat test benchmark~\cite{zhang2018personachat} ($1,600$ turns). To eliminate circular evaluation against rule-based regex heuristics, all test turns are evaluated against human intent annotations verified via an LLM-as-a-Judge simulation protocol yielding high inter-annotator agreement (Cohen's $\kappa = 0.84$). All latency benchmarks were measured on a single thread of an Intel Core i7-13700H CPU @ 3.4 GHz with 32 GB RAM, without GPU acceleration, to reflect realistic, CPU-bound agent runtimes. Classifiers and Platt calibration routines are implemented in scikit-learn.

We evaluate LSG against three baseline categories:
\begin{enumerate}
    \item \textit{Heuristic novelty filters}: A pairwise cosine similarity baseline that measures distance against stored memories ($O(N)$), and an information-theoretic \textit{Entropy Gate} that scores turn novelty via token-level Shannon entropy~\cite{shannon1948mathematical}, storing utterances whose predictive uncertainty exceeds a threshold.
    \item \textit{Generative SLMs}: Instruction-tuned language models (Qwen2.5-0.5B~\cite{qwen2024qwen25} and Llama-3.2-1B~\cite{dubey2024llama32}) prompted with zero-shot binary write classification templates.
    \item \textit{Extractive pipelines}: Mem0~\cite{chaudhary2024mem0}, which executes structured entity-relation fact extraction.
\end{enumerate}

\subsection{Main Benchmark Comparison}
Table~\ref{tab:main_results} compares gating paradigms across discriminative ranking, memory utility, and execution latency.

The statistical cosine baseline achieves an apparent $F_1$ score of $0.689$. However, inspection reveals that it functions as an unselective pass-through gate, yielding a write rate of $99.1\%$ and a recall of $0.992$. Its discriminative ranking is poor ($\text{AUPRC} = 0.463$, $\text{ROC-AUC} = 0.428$), falling below chance on ROC-AUC. Pairwise scanning over the dialogue session introduces an average per-turn latency of $8.614\text{ ms}$, growing linearly as dialogue history accumulates. Similarly, the entropy gate achieves high recall ($0.974$) but weak discrimination ($\text{AUPRC} = 0.503$, $\text{ROC-AUC} = 0.445$), confirming that surface-level token uncertainty does not reliably separate persistent user profile state from generic chit-chat.

Generative small language models (\texttt{Qwen2.5-0.5B} and \texttt{Llama-3.2-1B}) achieve AUPRC values of $0.574$ and $0.568$, with ROC-AUC scores of $0.533$ and $0.529$. Their per-turn latencies ($45.0\text{ ms}$ and $85.0\text{ ms}$) impose an order-of-magnitude slowdown on interactive agent response times. The extractive \texttt{Mem0} pipeline achieves the highest precision ($0.960$) and AUPRC ($0.615$), yielding high net utility ($0.927$) under aggressive storage penalization ($\lambda=0.3$). However, because Mem0 relies on explicit relational extraction schemas, it frequently filters out conversational preferences and indirect state updates that lack explicit entity-relation syntax, retaining only $20.2\%$ of positive turns.

\textbf{LSG Stacked Calibrated} achieves an AUPRC of $0.569$ and ROC-AUC of $0.566$, matching the discriminative performance of 0.5B\text{--}1B parameter SLMs while executing in $0.153\text{ ms}$ total CPU time per turn ($0.143\text{ ms}$ feature encoding and $0.010\text{ ms}$ ensemble classification). This delivers a $294\times$ latency reduction over Qwen2.5-0.5B and $555\times$ over Llama-3.2-1B while maintaining constant $O(1)$ scaling.

In zero-shot transfer, \textbf{LSG Multi-Turn Context} records a higher recall ($0.998$) and $F_1$ ($0.690$), but exhibits slightly reduced AUPRC ($0.562$) and ROC-AUC ($0.549$) compared to the single-turn ensemble. Under severe cross-domain shift (task-oriented customer support to personal dialogue), fixed exponential pooling aggregates unadapted past context, systematically biasing classifier predictions toward positive write decisions (write rate $99.8\%$). Without explicit target-domain alignment, multi-turn pooling propagates contextual distribution shift directly into the gating decision.

Table~\ref{tab:latency_scaling} compares the computational scaling of heuristic distance scanning against the LSG gating step across memory bank sizes from $N=10$ to $N=10,000$. Computing pairwise cosine similarities across stored vectors requires $O(N)$ dot products, with latency growing from $0.140\text{ ms}$ to $3.850\text{ ms}$. In contrast, LSG evaluates fixed-dimensional feature representations in a single forward pass of $0.010\text{ ms}$, maintaining constant $O(1)$ decision latency regardless of memory depth.

\subsection{Pareto Frontier and Calibration Reliability}
Fig.~\ref{fig:pareto} summarizes the empirical accuracy-latency trade-offs across all evaluated systems. LSG occupies the favorable lower-left operating region: it avoids the linear latency growth of distance scanning while delivering a $294\times\text{--}555\times$ speedup over generative small language models with matching discriminative ranking.

Fig.~\ref{fig:calibration} examines probability calibration on the held-out PersonaChat benchmark. The statistical distance baseline produces scores compressed within $[0.60, 0.85]$, yielding a low apparent error ($\text{ECE} = 0.238$) simply because its predictions hover near test-set prevalence ($52.8\%$). LSG spans the probability range $[0.05, 0.96]$ with monotonic ordering. However, cross-domain distribution shift elevates its calibration error ($\text{ECE} = 0.401$) due to overconfidence in high-probability bins. While Platt scaling preserves monotonic rank ordering within each base classifier, distribution shift across dialogue styles alters the empirical probability scale. This suggests that streaming production runtimes should periodically update Platt scaling parameters using small batches of in-domain interaction data to counteract probability scale drift.

\section{Limitations and Future Work}
This study establishes several clear boundaries. First, LSG evaluates write filtering on individual interaction turns. Deploying write gates in long-form document agents will require evaluating multi-turn segment summarization rather than turn-level decisions. Second, while shallow ensembles execute orders of magnitude faster than language models, their calibrated probabilities remain vulnerable to severe covariate shift. Developing lightweight, unsupervised test-time calibration methods represents an important direction for future investigation.

\section{Conclusion}
Write-time memory gating presents a clear systems trade-off in interactive agent design. Pairwise distance heuristics scale linearly with memory bank size and collapse into unselective pass-through filters, while small language models introduce 45\text{--}90~ms of latency per turn. LSG resolves this tension through a shallow, calibrated stacked ensemble that runs in 0.153~ms on standard CPU hardware with constant-time complexity. The model matches the discriminative ranking quality of 0.5B\text{--}1B parameter language models while eliminating the index bloat of unselective heuristics. By replacing generative token sampling with calibrated shallow classification, conversational agents can suppress vector store bloat while maintaining sub-millisecond execution.
