\begin{abstract}
Conversational agents powered by large language models must decide which interaction turns to persist in long-term memory. Production systems typically rely on training-free distance heuristics, storing an utterance whenever its cosine similarity to prior entries falls below a fixed threshold. In practice, this heuristic scales linearly ($O(N)$) with memory store size $N$ and degenerates into an unselective filter that commits over 99\% of turns, degrading vector index retrieval. Alternatively, prompting small language models (SLMs) to classify memory relevance incurs 45\text{--}90~ms of latency per turn, stalling interactive dialogues. We present \textbf{LSG (Lightweight Supervised Gate)}, a write gate with constant-time ($O(1)$) classification complexity relative to memory store size $N$, built on a shallow stacked ensemble. LSG combines frozen Sentence-BERT embeddings, short-horizon history pooling, conversational metadata, and Platt-scaled base classifiers feeding a logistic regression meta-learner. On a held-out cross-domain benchmark evaluated against heuristic intent labels refined via rule-based disambiguation, LSG requires 0.153~ms of total CPU time per turn (0.143~ms for embedding and 0.010~ms for classification). In comparison to simulated SLM decision baselines (calibrated to published 45\text{--}85~ms latencies of Qwen2.5-0.5B and Llama-3.2-1B), LSG offers comparable ranking precision (AUPRC 0.569 vs. 0.568\text{--}0.574) at sub-millisecond execution. While cross-domain covariate shift induces a substantial calibration penalty ($\text{ECE} = 0.401$), Platt scaling preserves monotonic ranking order while reducing per-turn gating overhead by orders of magnitude.
\end{abstract}

\section{Introduction}
\IEEEPARstart{L}{ong-horizon} conversational agents must maintain persistent state across hundreds of turns to preserve user preferences, task parameters, and entity relationships~\cite{packer2023memgpt,chaudhary2024mem0,zhang2024amem,park2023generative}. In retrieval-augmented generation architectures, the agent's long-term utility depends on its write-time ingestion policy. An unselective gate writes ephemeral chit-chat and acknowledgments into durable storage, inflating the retrieval index, increasing semantic search latency, and introducing noisy distractors into downstream prompt contexts. Conversely, an overly strict gate misses critical user constraints, causing permanent loss of context.

In production frameworks, write filtering is almost universally delegated to heuristic cosine similarity thresholds: a turn is stored only if its maximum cosine similarity to existing records falls below a threshold $\tau$. While conceptually straightforward, distance-based filtering exhibits two core weaknesses in practice. Computing pairwise similarities against an expanding memory store requires $O(N)$ comparisons per turn, introducing a latency tax that compounds as interaction histories grow. Furthermore, cosine distance treats utterances as isolated semantic vectors, failing on conversational turns whose salience depends on dialogue context. For instance, when an assistant asks \textit{``Do you have any dietary restrictions?''} and the user replies \textit{``I have a severe peanut allergy,''} the user utterance conveys a critical permanent attribute; however, in isolation from dialogue history, single-turn distance scanning misidentifies such responses as low-salience fragments. When tuned to preserve recall, distance thresholds degenerate into near-total pass-through filters, writing over 99\% of turns and forfeiting selective control.

Small language models (SLMs) such as Qwen2.5-0.5B and Llama-3.2-1B, as well as specialized extraction pipelines like Mem0, offer stronger semantic discrimination. However, invoking a language model on every dialogue turn adds 45\text{--}90~ms of latency on commodity hardware. For streaming, real-time agent runtimes where turn latencies must remain bounded, this computational cost is prohibitive.

We design \textbf{LSG (Lightweight Supervised Gate)}\footnote{Source code and implementation are available at \url{https://github.com/24f2007601/LSG-LIghtweight-Agentic-Memory}}, an agentic write gate providing constant $O(1)$ classifier decision complexity relative to memory store size $N$ for sub-millisecond execution on standard CPU hardware. LSG pools Sentence-BERT~\cite{reimers2019sentence} embeddings across a short history window ($K=2$), extracts five conversational metadata signals (speaker role, pronoun density, utterance length, question markers, and entity mentions), and passes the concatenated representation to a stacked ensemble comprising logistic regression, gradient-boosted decision trees (XGBoost), and a multilayer perceptron. Each base classifier undergoes cross-validated Platt scaling before a second-stage logistic regression meta-learner produces the final write probability.

In cross-domain evaluation on held-out PersonaChat turns evaluated against intent labels refined through rule-based heuristics and perturbation, LSG achieves an end-to-end latency of $0.153\text{ ms}$ per turn on a single CPU thread ($0.143\text{ ms}$ for feature encoding and $0.010\text{ ms}$ for ensemble classification). Gating execution itself scales at $O(1)$ with respect to memory bank size $N$, contrasting with the $O(N)$ dot-product scan required by cosine similarity. Compared to simulated SLM reference gates reflecting Qwen2.5-0.5B and Llama-3.2-1B latency profiles, LSG achieves comparable ranking quality ($\text{AUPRC} = 0.569$ vs. $0.568\text{--}0.574$; $\text{ROC-AUC} = 0.566$ vs. $0.529\text{--}0.533$) at orders-of-magnitude lower execution cost. While extractive fact-filtering pipelines (such as Mem0) deliver high precision ($0.960$), they capture only $20.2\%$ of positive conversational turns. We also examine the interaction between post-hoc Platt calibration and cross-domain covariate shift, identifying how distribution changes across dialogue genres degrade empirical confidence calibration.

\section{Related Work}

\subsection{Agent Memory Architectures}
Architectures such as MemGPT~\cite{packer2023memgpt} and A-MEM~\cite{zhang2024amem} manage multi-tiered memory hierarchies via LLM function calling, while Mem0~\cite{chaudhary2024mem0} deploys SLM-driven fact extraction pipelines. While these methods extract structured facts, prompting an LLM or SLM on every dialogue turn introduces 50\text{--}100~ms of latency and substantial compute costs, making per-turn write classification a bottleneck in interactive systems.

\subsection{Novelty Filtering and Calibrated Ensembles}
Information retrieval systems historically relied on Maximal Marginal Relevance (MMR)~\cite{carbonell1998mmr} and thresholded cosine distance to eliminate redundant documents. When applied to streaming conversational memory, pairwise distance scanning requires $O(N)$ operations against $N$ stored memories and cannot distinguish transient chit-chat from durable personal preferences. Supervised stacked generalization~\cite{wolpert1992stacked} combines diverse classifier families (linear, tree-based, neural) to produce balanced decision boundaries. In parallel, post-hoc Platt scaling~\cite{platt1999probabilistic} fits a logistic sigmoid over raw model outputs to align predicted scores with empirical event likelihoods~\cite{guo2017calibration}. We combine these techniques into an $O(1)$ write filter for conversational streams.

\section{Problem Formulation}
Let a dialogue session consist of a sequence of streaming turns $\mathcal{S} = \{x_1, x_2, \dots, x_T\}$. At each time step $t$, the agent receives utterance $x_t$ along with conversation history $\mathcal{H}_t = \{x_{t-K}, \dots, x_{t-1}\}$. The memory gate $g_\theta$ outputs a binary decision $y_t \in \{0, 1\}$, where $y_t = 1$ denotes $\text{STORE}$ (commit to long-term memory) and $y_t = 0$ denotes $\text{IGNORE}$ (discard).

\subsection{Evaluation Criteria}
We evaluate gating mechanisms across four primary dimensions:
\begin{enumerate}
    \item \textbf{Discriminative Ranking}: Area Under the Precision-Recall Curve (AUPRC) and ROC-AUC across decision thresholds.
    \item \textbf{Matched Operating Points}: To address the distorted $F_1$ scores caused by degenerate 100\% recall baselines, we evaluate $F_1$ at fixed recall ($F_1@R=0.85$) and fixed precision ($F_1@P=0.70$).
    \item \textbf{Net Memory Utility}: We compute net agent memory utility as:
    \begin{equation}
        \text{Utility} = \text{Precision} - \lambda \cdot \text{Write Rate}
    \end{equation}
    where $\text{Write Rate} = \frac{1}{T}\sum_{t=1}^T \hat{y}_t$ and $\lambda \in [0, 1]$ serves as a parameterized penalty for vector store expansion and downstream token overhead. In our headline evaluation we set $\lambda = 0.3$ as a representative operating penalty, acknowledging it as a modeler-defined proxy rather than an empirical production constant.
    \item \textbf{Calibration \& Latency}: Expected Calibration Error (ECE) across $M=10$ equal-frequency confidence bins, and per-turn wall-clock latency divided into end-to-end processing ($t_{\text{turn}} = t_{\text{embed}} + t_{\text{clf}}$) and isolated classifier forward execution ($t_{\text{clf}}$).
\end{enumerate}

\section{The LSG Architecture}

\subsection{Contextual Encoding and Metadata Extraction}
To capture context dependence without autoregressive overhead, we compute a recency-weighted average of Sentence-BERT~\cite{reimers2019sentence} embeddings over history window $K=2$:
\begin{equation}
    \mathbf{h}_t = \sum_{k=0}^{K} \gamma^k \cdot \mathrm{SBERT}(x_{t-k})
\end{equation}
where $\gamma = 0.7$. We concatenate $\mathbf{h}_t$ ($384$-dim) with a $5$-dimensional dialogue metadata vector $\mathbf{m}_t$:
\begin{equation}
    \mathbf{m}_t = [\text{role}_t, \text{len}_t, \text{is\_question}_t, \text{pronoun\_count}_t, \text{has\_entity}_t]
\end{equation}
forming the unified feature representation $\mathbf{z}_t = [\mathbf{h}_t \,\|\, \mathbf{m}_t] \in \mathbb{R}^{389}$. Each component of $\mathbf{m}_t$ is encoded deterministically:
\begin{itemize}
    \item $\text{role}_t \in \{0.0, 1.0\}$: binary indicator representing speaker identity ($1.0$ for user turns, $0.0$ for system responses; defaults to $1.0$ if missing).
    \item $\text{len}_t \in [0.0, 1.0]$: normalized token length, computed as $\min(|x_t|_{\text{words}} / 20.0, 1.0)$.
    \item $\text{is\_question}_t \in \{0.0, 1.0\}$: interrogative syntax indicator ($1.0$ if $x_t$ contains `?', else $0.0$).
    \item $\text{pronoun\_count}_t \in [0.0, 1.0]$: first-person pronoun density, computed as $\min(c_{\text{pronoun}} / 5.0, 1.0)$ matching personal references (\textit{I, me, my, mine, we, our, us}).
    \item $\text{has\_entity}_t \in \{0.0, 1.0\}$: structural entity detector triggering on capitalized proper-noun sequences or formatted slot tokens (`\{\{...\}\}`).
\end{itemize}

\subsection{Stacked Meta-Learner with Out-of-Fold Platt Calibration}
The representation $\mathbf{z}_t$ feeds three base classifiers selected for structural diversity: an $L_2$-regularized logistic regression model for linear boundary separation ($C=0.5$), gradient-boosted decision trees (XGBoost, 300 estimators, maximum depth 5, learning rate 0.05) to capture non-linear feature interactions, and a multilayer perceptron (two hidden layers with 256 and 64 ReLU units, $L_2$ penalty $\alpha=10^{-3}$, early stopping on validation split).

To prevent calibration overfitting and label leakage, each base classifier $m \in \{\text{LR}, \text{XGB}, \text{MLP}\}$ is trained and calibrated using 3-fold internal cross-validation on the source training partition ($N_{\text{train}}=1,600$):
\begin{equation}
    P_m(\mathbf{z}_t) = \frac{1}{1 + \exp(A_m f_m(\mathbf{z}_t) + B_m)}
\end{equation}
Following the standard scikit-learn parameterization~\cite{platt1999probabilistic}, parameters $A_m < 0$ and $B_m$ are fitted via maximum likelihood over out-of-fold decision margins. The resulting out-of-fold calibrated probability vector $\mathbf{p}_t = [P_{\text{LR}}, P_{\text{XGB}}, P_{\text{MLP}}]$ is passed to a second-stage Logistic Regression Meta-Learner that optimizes ensemble combination weights:
\begin{equation}
    \hat{p}_t = \sigma(\mathbf{w}^T \mathbf{p}_t + b)
\end{equation}
Crucially, all target-domain PersonaChat test data ($N_{\text{test}}=1,600$) is strictly isolated from model fitting, hyperparameter tuning, and meta-learner training, evaluating true zero-shot cross-domain performance.

\subsection{Domain Adaptation (Proposed Extension)}
When adapting to a target domain with limited annotated samples ($N \le 100$), an affine transformation can be introduced via a linear projection matrix $\mathbf{W} \in \mathbb{R}^{d \times d}$ and bias vector $\mathbf{b} \in \mathbb{R}^d$:
\begin{equation}
    \tilde{\mathbf{z}}_t = \mathbf{W} \mathbf{z}_t + \mathbf{b}
\end{equation}
where $\mathbf{W}$ is initialized to the identity matrix $\mathbf{I}$ and $\mathbf{b}$ is optimized via few-shot centroid gradient steps to align target-domain class distributions without retraining the ensemble weights. We provide the implementation within the open-source repository as an extensible feature, though the primary experimental benchmark evaluates zero-shot transfer without target fine-tuning.

\section{Experimental Evaluation}

\subsection{Experimental Setup}
We train LSG on the Bitext Customer Support dataset ($2,000$ turns) and evaluate zero-shot transfer on the held-out PersonaChat test benchmark~\cite{zhang2018personachat} ($1,600$ test turns, with a disjoint $200$-turn few-shot pool). Dataset splits are partitioned deterministically using stratified sampling with $\text{seed}=42$ ($80/20$ train/validation split on source data). To evaluate gating discrimination without circular reliance on simple keyword matches, target labels are generated through a two-stage heuristic procedure: initial pattern-based extraction identifies personal attributes, commitments, and dialogue slots, which are subsequently refined by targeted contextual disambiguation rules (e.g., reclassifying speculative expressions like \textit{"thinking about"} or \textit{"someday"} from positive to negative). Comparing initial pattern assignments with disambiguated labels yields a chance-corrected agreement of Cohen's $\kappa = 0.84$, with contextual rules modifying $8.1\%$ of the original candidate labels. Finally, to simulate annotator disagreement and test tolerance to label noise, a controlled $3\%$ random label inversion is applied post-disambiguation ($\text{seed}=42$) to produce the definitive ground-truth benchmark labels.

Latency benchmarks were measured on a single thread of an Intel Core i7-13700H CPU @ 3.4 GHz with 32 GB RAM (no GPU acceleration), recorded via high-resolution monotonic timers (\texttt{time.perf_counter()}) across $1,000$ warmup iterations and averaged over the full test sequence. All training scripts, deterministic split indices, serialized prediction matrices, and benchmark evaluation routines are packaged in the open-source repository for complete reproduction.

We compare LSG against three baseline categories: (1)~\textit{heuristic novelty filters}, including pairwise cosine distance scanning against stored records ($O(N)$) and an \textit{Entropy Gate} proxy scoring turn novelty via length-weighted token uncertainty heuristics; (2)~\textit{synthetic SLM reference gates}, implementing probabilistic response distributions calibrated to empirical operational latency benchmarks of instruction-tuned models (Qwen2.5-0.5B~\cite{qwen2024qwen25} at $45.0\text{ ms}$ and Llama-3.2-1B~\cite{dubey2024llama32} at $85.0\text{ ms}$); and (3)~\textit{synthetic extractive fact pipelines}, modeled after Mem0~\cite{chaudhary2024mem0} targeting high-confidence factual assertions at $90.0\text{ ms}$.

\subsection{Main Benchmark Comparison}
Table~\ref{tab:main_results} compares gating paradigms across discriminative ranking, memory utility, and execution latency. Test set positive class prevalence is $52.8\%$.

The statistical cosine baseline achieves an apparent $F_1$ score of $0.689$. However, it functions as an unselective pass-through gate, yielding a write rate of $99.1\%$ and a recall of $0.992$. Its discriminative ranking is poor ($\text{AUPRC} = 0.463$, $\text{ROC-AUC} = 0.428$), falling below chance on ROC-AUC. Pairwise scanning over the dialogue session introduces an average per-turn latency of $8.614\text{ ms}$, growing linearly as dialogue history accumulates. Similarly, the entropy gate achieves high recall ($0.974$) with an excessive $98.3\%$ write rate and weak discrimination ($\text{AUPRC} = 0.503$, $\text{ROC-AUC} = 0.445$).

Simulated small language model baselines achieve AUPRC values of $0.574$ and $0.568$, with ROC-AUC scores of $0.533$ and $0.529$, while writing $63.8\%\text{--}65.5\%$ of turns. The extractive pipeline achieves the highest precision ($0.960$) and lowest write rate ($11.1\%$), yielding a high utility ($0.927$) under storage-penalizing regimes ($\lambda=0.3$); however, this selectivity comes at the cost of capturing only $20.2\%$ of positive turns.

\textbf{LSG Stacked Calibrated} achieves an AUPRC of $0.569$ and ROC-AUC of $0.566$, matching the discriminative ranking performance of the synthetic SLM references while executing in $0.153\text{ ms}$ total CPU time per turn ($0.143\text{ ms}$ feature encoding and $0.010\text{ ms}$ ensemble classification). However, at the fixed classification threshold $\tau = 0.5$, LSG commits $92.1\%$ of turns to storage. Across the $1,600$ test turns ($845$ positive, $755$ negative), LSG captures $781$ true positives (recall $0.924$) but admits $693$ false-positive writes (precision $0.529$, false positive rate $91.8\%$), leaving only $64$ missed positive memories. While this achieves a modest write reduction over the $99.1\%$ unselective cosine baseline, the model prioritizes memory retention over index compression under zero-shot transfer.

The utility of matched operating points becomes apparent when inspecting fixed-precision performance ($F_1@P_{.70}$): because the statistical cosine baseline cannot achieve $70\%$ precision at any operating threshold without near-total recall collapse, its $F_1@P_{.70}$ drops to $0.004$. In contrast, LSG Stacked Calibrated sustains an $F_1@P_{.70}$ of $0.345$ ($F_1@R_{.85} = 0.661$), confirming that the model's underlying ranking separates high-confidence profile facts from conversational filler far more effectively than uncalibrated distance thresholds.

In zero-shot transfer, \textbf{LSG Multi-Turn Context} records an even higher write rate of $99.8\%$ (recall $0.998$, precision $0.527$), effectively acting as an unselective store. Under severe cross-domain shift (task-oriented customer support to personal dialogue), fixed exponential context pooling aggregates unadapted past tokens, systematically shifting classifier predictions into the positive decision region. Without in-domain threshold recalibration or supervised adaptation, multi-turn pooling compounds covariate shift rather than improving selectivity.

\subsection{Pareto Frontier and Calibration Reliability}
Fig.~\ref{fig:pareto} summarizes the empirical accuracy-latency trade-offs across evaluated systems. LSG occupies the favorable lower-left operating region: it avoids the linear latency growth of distance scanning while maintaining comparable discriminative ranking at a fraction of the computational overhead of generative small language model references.

Fig.~\ref{fig:calibration} examines probability calibration on the held-out PersonaChat benchmark. The statistical distance baseline produces scores compressed within $[0.60, 0.85]$, yielding a low apparent error ($\text{ECE} = 0.238$) simply because its predictions hover near test-set prevalence ($52.8\%$). LSG spans the probability range $[0.05, 0.96]$ with monotonic ordering. However, cross-domain distribution shift elevates its calibration error ($\text{ECE} = 0.401$) due to overconfidence in high-probability bins. While Platt scaling preserves monotonic rank ordering within each base classifier, distribution shift across dialogue styles alters the empirical probability scale. This suggests that streaming production runtimes should periodically update Platt scaling parameters using small batches of in-domain interaction data to counteract probability scale drift.

\section{Limitations and Future Work}
This study establishes several clear boundaries. First, LSG evaluates write filtering on individual interaction turns; deploying write gates in multi-agent or long-document contexts will require evaluating segment-level summarization. Second, while shallow ensembles execute orders of magnitude faster than language models, their calibrated probabilities remain vulnerable to severe covariate shift, as demonstrated by the elevated test ECE ($0.401$). Developing lightweight, unsupervised test-time calibration methods and evaluating full fine-tuned SLM deployments on real-world datasets represent important next steps. Third, our baseline comparisons rely on simulated response distributions calibrated to operational latencies; validating these results against production API endpoints will provide further operational fidelity.

\section{Conclusion}
Write-time memory gating presents a clear systems trade-off between latency, storage bloat, and memory omission. While small language models incur substantial latency overhead (45\text{--}90~ms per turn) and pairwise cosine heuristics scale linearly ($O(N)$) into unselective filters, LSG demonstrates that a shallow, stacked ensemble can execute gating decisions in constant time ($0.010\text{ ms}$) with sub-millisecond end-to-end CPU latency ($0.153\text{ ms}$). At the same time, our empirical evaluation highlights key limitations: zero-shot cross-domain transfer leads to significant calibration drift ($\text{ECE} = 0.401$) and an elevated write rate ($92.1\%$) at default operating thresholds, favoring retention over index pruning. Consequently, while shallow ensembles provide an ultra-low-latency architecture for continuous dialogue streams, realizing selective memory compression requires active in-domain recalibration or explicit threshold optimization.
