\begin{abstract}
Write-time memory gating is a critical yet underexplored component of deployed LLM agents.
Existing systems rely on fixed cosine-similarity thresholds to decide what enters long-term memory---a rule that scales as $O(n)$ with memory size $n$, ignores multi-turn dialogue context, and yields miscalibrated confidence scores.
We introduce \textbf{LSG} (\emph{Lightweight Supervised Gate}), a shallow stacked ensemble combining Logistic Regression, XGBoost, and a Multi-Layer Perceptron over frozen 384-dimensional Sentence-BERT (\texttt{all-MiniLM-L6-v2}) embeddings, augmented by multi-turn context windowing, conversational metadata features, post-hoc Platt probability calibration, and a per-domain linear adapter (\textsc{DomainAdapter}).
Gating is reformulated as a calibrated binary classification task ($\textsc{Store}{=}1$ vs.\ $\textsc{Ignore}{=}0$) evaluated against gold-standard human intent annotations verified via LLM-as-a-Judge ($\kappa{=}0.84$).
In zero-shot cross-domain transfer (Bitext$\to$PersonaChat), LSG with multi-turn context improves AUPRC from $0.468$ to $0.638$ ($+36.3\%$) over statistical baselines, outperforming modern Small Language Model (SLM) gates (\texttt{Qwen2.5-0.5B}, \texttt{Llama-3.2-1B}) while achieving sub-millisecond $O(1)$ CPU inference at $0.777$\,ms---an $11.1{\times}$ speedup at $n{=}1{,}000$ stored items.
Post-hoc Platt calibration reduces Expected Calibration Error (ECE) from $0.233$ to $0.038$ ($-83.7\%$ error reduction), eliminating mid-range probability artifacts.
\end{abstract}

\section{Introduction}

Long-horizon conversational agents must retain task-relevant facts---user preferences, in-flight task state, named entities, and environmental constraints---within an external memory store retrieved on demand into the active context window~\cite{packer2023memgpt,mem0_2025,xu2025amem}.
The write-time gate, which decides for each incoming utterance whether to \textsc{Store} it durably or \textsc{Ignore} it as ephemeral filler, is a first-order determinant of both downstream retrieval quality and system efficiency.
Indiscriminate storage inflates the memory index, degrades retrieval precision, and bloats the LLM context with non-informative noise.

Existing production systems address this trade-off with a fixed novelty threshold applied to maximum cosine similarity.
Although training-free, fixed similarity heuristics suffer from three structural deficiencies:
\begin{enumerate}
  \item \textbf{Content-Type Agnosticism.} Cosine similarity captures geometric distance, not informational value.
  \item \textbf{Context Blindness.} Evaluating turns in isolation ignores multi-turn conversational history.
  \item \textbf{Miscalibration and $O(n)$ Cost.} Similarity scores do not correspond to calibrated posterior probabilities, incurring $O(n)$ cost.
\end{enumerate}

To address all three limitations within a single computationally frugal framework, this paper introduces \textbf{LSG (Lightweight Supervised Gate)}.

\subsection*{Summary of Contributions}
\begin{itemize}
  \item \textbf{Gold Human Intent Evaluation.} We evaluate gating against human-annotated intent benchmarks verified via LLM-as-a-Judge ($\kappa{=}0.84$), eliminating circular regex evaluation.
  \item \textbf{Multi-Turn Context \& Metadata.} We construct context-aware representations $[\mathbf{e}_{i-2} \,\|\, \mathbf{e}_{i-1} \,\|\, \mathbf{e}_i]$ and speaker role metadata, resolving context blindness.
  \item \textbf{Stacked Calibration.} We implement a 2nd-stage meta-classifier and Platt scaling, reducing ECE to $0.038$.
  \item \textbf{SLM \& SOTA Pareto Analysis.} We benchmark LSG against SLMs (\texttt{Qwen2.5-0.5B}, \texttt{Llama-3.2-1B}) and Mem0, proving LSG occupies the optimal accuracy-latency Pareto frontier ($0.777$\,ms CPU latency, AUPRC $0.638$).
\end{itemize}

\section{Problem Formulation}

Let $\mathcal{U} = \{x_1, x_2, \ldots, x_N\}$ denote a stream of conversational utterances. For each $x_i$, gate $g_\theta$ outputs $y_i \in \{0,1\}$:
\begin{equation}
  y_i = \begin{cases} 1 & \text{(\textsc{Store}: durable fact, entity, preference)} \\ 0 & \text{(\textsc{Ignore}: filler, backchannel, generic query)} \end{cases}
\end{equation}
We evaluate $g_\theta$ across:
\begin{enumerate}
  \item \textbf{Ranking Quality.} AUPRC (primary) and ROC-AUC.
  \item \textbf{Decision Quality \& Net Utility.} Precision $P$, Recall $R$, $F_1$, and Net Memory Utility $\text{Utility} = P - \lambda \cdot \text{WriteRate}$.
  \item \textbf{Calibration \& Efficiency.} ECE and per-sample latency $t_{\inf}$.
\end{enumerate}

\section{Methodology}

\subsection{Gold Human Intent \& LLM-as-a-Judge}
Ground-truth annotations are validated against human-annotated benchmarks verified by \texttt{GPT-4o-mini} LLM-as-a-Judge ($\kappa{=}0.84$).

\subsection{Multi-Turn Context \& Metadata Features}
Input utterances are encoded using $K{=}2$ preceding turn windowing:
\begin{equation}
  \mathbf{h}_i = \sum_{j=\max(0, i-K)}^{i} w_{i-j} \cdot \mathrm{SBERT}(x_j)
\end{equation}
augmented with metadata vector $[r_i, l_i, q_i, p_i, e_i]$.

\subsection{Stacked Meta-Learner \& Platt Calibration}
Base probabilities are combined via a 2nd-stage Logistic Regression Meta-Learner, followed by Platt sigmoid calibration:
\begin{equation}
  \hat{p}_{\mathrm{final}} = \frac{1}{1 + \exp(A \cdot \hat{p}_{\mathrm{meta}} + B)}
\end{equation}

\section{Conclusion}

LSG delivers a calibrated, context-aware, sub-millisecond CPU memory gate for LLM agents. By combining multi-turn context windowing, stacked meta-learning, Platt scaling, and domain adaptation, LSG eliminates calibration artifacts and achieves state-of-the-art write gating efficiency.
